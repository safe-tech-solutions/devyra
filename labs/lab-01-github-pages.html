Lab 01: Pipeline Git + SSH Key + GitHub Pages no Ubuntu

Documentado por Celso Lima (@celsosre)

1. Objetivo

Configurar um ambiente Ubuntu (Multipass) para clonar um repositório GitHub de forma segura via SSH e implantar automaticamente alterações web no domínio customizado devyra.com.br.

2. Passos Executados

Passo 1: Instalação e Identidade Git

sudo apt update && sudo apt install git -y
git config --global user.name "safe-tech-solutions"
git config --global user.email "safehousetechnologia@gmail.com"

Passo 2: Geração de Chave SSH Ed25519

ssh-keygen -t ed25519 -C "safehousetechnologia@gmail.com"
cat ~/.ssh/id_ed25519.pub

A chave pública foi vinculada no menu Settings -> SSH Keys do GitHub.

Passo 3: Validação da Conexão e Clone

ssh -T git@github.com
git clone git@github.com:safe-tech-solutions/devyra.git
cd devyra

Passo 4: Alteração e Pipeline de Deploy

git add .
git commit -m "feat: atualiza layout da aplicação"
git push origin main

3. Resultado Validado

A alteração refletiu automaticamente no domínio devyra.com.br via GitHub Pages com certificado de segurança ativo.
