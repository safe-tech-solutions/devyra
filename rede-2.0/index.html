Projeto 01

Monte um Lab de Troubleshooting de Redes no Linux

Crie hosts Linux isolados com namespaces de rede e pares veth. Inspecione interfaces, rotas, tabelas ARP/neighbor, sockets e tráfego.

01
Objetivo
  • Configurar hosts isolados via namespaces.
  • Conectá-los com pares veth.
  • Praticar troubleshooting de nível real.
O Que Vai Construir
  • 3 hosts Linux isolados
  • Rede virtual veth
  • Testes de conectividade
Ferramentas
ipsspingtcpdump
1Criar Namespaces
sudo ip netns add ns1 sudo ip netns add ns2
2Pares Veth
sudo ip link add veth1 type veth peer name veth2 sudo ip link set veth1 netns ns1 sudo ip link set veth2 netns ns2
🔑 Conclusão

Problemas de rede são fáceis de resolver quando reproduzidos.

✅ Habilidade

Base sólida para containers e Kubernetes.
