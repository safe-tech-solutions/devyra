01

Introdução ao Linux

O que é o Linux?

O Linux é um kernel de sistema operacional de código aberto, semelhante ao Unix, criado por Linus Torvalds em 1991. Ele gerencia hardware e recursos. Combinado com ferramentas, bibliotecas e aplicativos, torna-se um Sistema Operacional completo.

Por que o Linux domina servidores e nuvem?
  • Código Aberto e Gratuito: sem custos de licença, impulsionado pela comunidade.
  • Estável e Confiável: construído para manter alta disponibilidade.
  • Seguro por Design: forte modelo de permissões e comunidade ativa.
  • Alto Desempenho: uso de recursos leve e eficiente.
  • Nativo em Nuvem: base de contêineres, Kubernetes e DevOps.
  • Padrão da Indústria: usado pelos principais provedores de nuvem.
Principais distribuições
  • Ubuntu: amigável, excelente comunidade.
  • Rocky / AlmaLinux: nível empresarial, prontas para produção.
  • RHEL: suporte empresarial e alta confiabilidade.
  • Debian: muito estável e seguro.
  • Arch: leve, rolling release para avançados.
02

Sistema de Arquivos Linux

Tudo no Linux é um arquivo. Tudo parte da raiz /.

DiretórioPropósitoExemplos
/etcConfigurações do sistema./etc/nginx/nginx.conf, /etc/ssh/sshd_config
/varDados variáveis, logs e DBs./var/log/syslog, /var/lib/mysql
/homeDiretórios de usuários./home/ubuntu/
/usrProgramas e bibliotecas./usr/bin, /usr/lib
/optSoftwares de terceiros./opt/docker/
/tmpTemporários./tmp/app.sock
03

Navegando no Linux

  • pwd — diretório atual.
  • cd /var/log — trocar diretório.
  • ls -lah — listar com detalhes e ocultos.
  • tree -L 2 — árvore.
  • find /var/log -name "*.log" — buscar.
  • locate nginx.conf — busca indexada.
bash
$ pwd
/home/devops
$ ls -lah /var/log
$ find /etc -name "*.conf" -type f
$ cd -   # volta ao anterior
04

Trabalhando com Arquivos e Diretórios

  • touch file.txt — cria arquivo vazio.
  • mkdir -p /opt/app/logs — cria pastas aninhadas.
  • cp -r /etc/nginx /backup/ — copia recursivo.
  • mv old.txt new.txt — move ou renomeia.
  • rm -r olddir/ — remove diretório.
  • ln -s /var/log/app.log app.log — link simbólico.
05

Visualizando e Editando Arquivos

  • cat /etc/hosts — arquivo pequeno.
  • less /var/log/syslog — arquivo grande.
  • head -n 20 / tail -n 50 — início e fim.
  • tail -f /var/log/nginx/access.log — tempo real.
  • nano / vim — editores.
vim — essencial
i → inserir | Esc → normal | :w → salvar | :q → sair | :wq → salvar e sair | :q! → sair sem salvar
06

Permissões no Linux

Usuário, Grupo e Outros com r, w e x.

bash
$ chmod 755 script.sh          # rwxr-xr-x
$ chmod u+x script.sh
$ chown -R user:group /opt/app
$ chgrp -R webteam /var/www
07

Usuários e Grupos

Princípio do Menor Privilégio: cada um só com o acesso necessário.

bash
$ sudo useradd -m alice
$ sudo passwd alice
$ sudo usermod -aG devops alice
$ sudo groupadd devops
$ groups alice
08

Processos

Todo processo tem um PID.

bash
$ ps aux
$ top / htop
$ pgrep -l nginx
$ kill 1234       # suave SIGTERM
$ kill -9 1234    # força SIGKILL
$ killall nginx
09

Serviços do Sistema (systemd)

O systemd gerencia o ciclo de vida dos serviços.

bash
$ sudo systemctl start nginx
$ sudo systemctl stop nginx
$ sudo systemctl restart nginx
$ sudo systemctl reload nginx
