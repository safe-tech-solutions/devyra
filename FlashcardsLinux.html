Navegação de Diretórios

3 cards
Card 01
Qual comando exibe o caminho completo do diretório atual onde você está?
🔄 Clique para ver a resposta
✅ Resposta
pwd
Print Working Directory
Exemplo de saída: /home/usuario/documentos
Card 02
Qual comando lista os arquivos e pastas do diretório atual?
🔄 Clique para ver a resposta
✅ Resposta
ls
List
💡 Dica: ls -la lista todos os arquivos (incluindo ocultos) em formato detalhado.
Card 03
Como mudar de diretório no Linux? E como voltar para o diretório pai (anterior)?
🔄 Clique para ver a resposta
✅ Resposta
cd <caminho>
Change Directory
• Entrar: cd <caminho>
• Voltar um nível: cd ..
• Ir para home: cd ~ ou apenas cd

Manipulação de Arquivos e Pastas

5 cards
Card 04
Como criar uma nova pasta (diretório)?
🔄 Clique para ver a resposta
✅ Resposta
mkdir <nome_da_pasta>
Make Directory
💡 Dica: mkdir -p pasta/subpasta cria a estrutura completa de uma vez.
Card 05
Qual comando cria um arquivo vazio ou atualiza a data/hora de modificação de um arquivo existente?
🔄 Clique para ver a resposta
✅ Resposta
touch <nome_do_arquivo>
Exemplo: touch notas.txt
Card 06
Qual comando é usado para copiar arquivos? Como copiar diretórios inteiros?
🔄 Clique para ver a resposta
✅ Resposta
cp <origem> <destino>
Copy
Para diretórios, use a flag recursiva:
cp -r <pasta_origem> <pasta_destino>
Card 07
Qual comando serve tanto para mover quanto para renomear arquivos e pastas?
🔄 Clique para ver a resposta
✅ Resposta
mv <origem> <destino>
Move
• Renomear: mv antigo.txt novo.txt
• Mover: mv arquivo.txt /caminho/pasta/
Card 08
Como remover (deletar) um arquivo? E como remover uma pasta com conteúdo?
🔄 Clique para ver a resposta
✅ Resposta
rm <arquivo>
Remove
• Para pastas: rm -r <pasta>
⚠️ rm -rf deleta recursivamente e sem confirmação. Não há "Lixeira" no terminal!

Leitura e Busca de Conteúdo

3 cards
Card 09
Qual comando exibe todo o conteúdo de um arquivo de texto diretamente no terminal?
🔄 Clique para ver a resposta
✅ Resposta
cat <arquivo>
Concatenate
Exemplo: cat script.py
Card 10
Quais comandos exibem apenas o início ou o fim de um arquivo?
🔄 Clique para ver a resposta
✅ Resposta
head / tail
• Início: head <arquivo> (10 primeiras linhas)
• Fim: tail <arquivo> (10 últimas linhas)
💡 Logs em tempo real: tail -f arquivo.log
Card 11
Qual comando busca por padrões de texto dentro de arquivos?
🔄 Clique para ver a resposta
✅ Resposta
grep "<termo>" <arquivo>
Exemplo: grep "erro" log.txt
💡 Flag -i ignora maiúsculas/minúsculas: grep -i "erro" log.txt

Sistema, Permissões e Ajuda

4 cards
Card 12
Como executar um comando com privilégios de administrador (root)?
🔄 Clique para ver a resposta
✅ Resposta
sudo <comando>
SuperUser DO
Exemplo: sudo apt update
Card 13
Qual comando altera as permissões de leitura, escrita e execução de um arquivo?
🔄 Clique para ver a resposta
✅ Resposta
chmod <permissões> <arquivo>
Change Mode
Exemplo: chmod +x script.sh (torna o arquivo executável).
Card 14
Como ver o manual/documentação oficial de qualquer comando no terminal?
🔄 Clique para ver a resposta
✅ Resposta
man <comando>
Manual
Exemplo: man ls
💡 Pressione q para sair do manual.
Card 15
Qual comando limpa a tela do terminal e qual é o seu atalho de teclado equivalente?
🔄 Clique para ver a resposta
✅ Resposta
clear
• Comando: clear
• Atalho de teclado: Ctrl + L
💡 Dica de Estudo

Tente praticar esses comandos abrindo um terminal e executando um por um em uma pasta temporária de testes. Por exemplo, crie uma pasta com mkdir teste e pratique todos os comandos dentro dela. A prática constante é a melhor forma de memorizar!
