Biblioteca prática · Devyra

Comandos para usar o ChatGPT de um jeito mais prático.

Um guia de atalhos de prompt para estudar, organizar ideias, resolver problemas, criar conteúdo e orientar imagens. Escolha um comando, adapte o exemplo e copie com um clique.

Explorar comandos Como usar
Importante: estes comandos são atalhos de instrução criados para orientar a resposta. Eles não são comandos oficiais do ChatGPT. O resultado depende do modelo, do contexto e do prompt usado.

Como usar

Você pode escrever o comando antes do pedido e copiar qualquer exemplo para adaptar.

1. Escolha/EL10
Para simplificar um assunto.
2. Combine/EL10 + /activequiz
Para aprender e testar.
3. AdapteTroque o texto do exemplo pelo seu contexto.
4. CopieUse o botão Copiar e cole onde quiser.
